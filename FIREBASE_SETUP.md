# Firebase setup for CerySAI (beginner guide)

You only do this once. Total time: ~15 minutes.

## 0. What you need installed
- Flutter (run `flutter doctor` - it should be mostly green)
- Node.js (https://nodejs.org) - needed for the Firebase CLI
- A Google account

## 1. Create the Firebase project
1. Go to https://console.firebase.google.com and click **Create a project**.
2. Name it `cerysai`. You can turn Google Analytics off. Click **Create**.

## 2. Turn on Email/Password login
1. In the left menu: **Build > Authentication > Get started**.
2. Open the **Sign-in method** tab, choose **Email/Password**, switch **Enable** on, press **Save**.

## 3. Create the database (Firestore)
1. Left menu: **Build > Firestore Database > Create database**.
2. Pick the location closest to your users (for India: `asia-south1` Mumbai). Choose **Production mode**. Click **Create**.
3. Open the **Rules** tab, delete everything, paste the contents of `firestore.rules` from this project, press **Publish**.
   (This lets each user read/write only their own profile.)

## 4. Connect the app to Firebase (this creates firebase_options.dart)
Run these in a terminal:

```bash
npm install -g firebase-tools
firebase login
dart pub global activate flutterfire_cli
```
If `flutterfire` is "not found" afterwards, add the Dart pub cache bin folder to your PATH
(Windows: `%LOCALAPPDATA%\Pub\Cache\bin`, Mac/Linux: `$HOME/.pub-cache/bin`) and reopen the terminal.

Then inside the project folder (the one containing pubspec.yaml):
```bash
flutter create .          # only needed once, creates android/ios folders
flutter pub get
flutterfire configure
```
- Select your `cerysai` project.
- Select platforms: **android** (and **ios** if you use a Mac).
- When it finishes, it overwrites `lib/firebase_options.dart` and adds `android/app/google-services.json`.

## 5. Android minimum SDK
Open `android/app/build.gradle.kts` (or `build.gradle` on older projects) and make sure:
```
minSdk = 23
```
(In older files: `minSdkVersion 23`.) Firebase Auth needs 23 or higher.

## 6. Run
```bash
flutter run
```
Tap **Get Started > Continue > fill the form > Create Account**.
Check it worked: Firebase console > Authentication > Users (new user), and Firestore > users (name, email, location, landAcres).

## Troubleshooting
| Problem | Fix |
|---|---|
| App shows "Firebase is not set up yet" | Step 4 not done - run `flutterfire configure` and restart (full stop + run, not hot reload) |
| `operation-not-allowed` | Step 2 - Email/Password not enabled |
| `permission-denied` after signup | Step 3 - rules not published |
| `network-request-failed` | Emulator has no internet / check Wi-Fi |
| Gradle / minSdk error | Step 5 |
| iOS build issues | Need a Mac + Xcode; in `ios/Podfile` set `platform :ios, '13.0'` |

## How the code is organised
```
lib/
  main.dart                 Firebase init + runApp
  app.dart / app_routes.dart  MaterialApp and route table
  firebase_options.dart     generated by flutterfire (placeholder until then)
  core/                     theme, route names, shared widgets
  models/app_user.dart      farmer profile model
  services/auth_service.dart  ALL Firebase login/signup/profile code
  features/
    auth/                   splash, login, signup, auth_gate
    home/ plant_doctor/ crops/ assistant/ weather/ schemes/ language/ voice/ profile/
```
`AuthGate` watches the login state: logged in -> Home, logged out -> Splash.

## Email verification (already built into the app)
- After signup, Firebase emails a verification link. Until the user taps it, the app shows the
  "Verify your email" screen instead of Home. It re-checks every 3 seconds and lets users resend (60s cooldown).
- To change the email wording/sender name: Firebase console > Authentication > **Templates** > Email address verification (pencil icon).
- The default sender is `noreply@<your-project>.firebaseapp.com` and may land in spam. For better delivery, set a
  custom domain in the same Templates page (optional).
- Test with a real inbox you can open (Gmail etc.).
